# Assignment C: VLM Advanced

## 1. Project Overview

This project studies whether Direct Preference Optimization (DPO) with
Low-Rank Adaptation (LoRA) can improve the visual grounding of image
descriptions generated by an open-source Vision-Language Model (VLM).

The optimization goal is to generate concise image descriptions that
remain faithful to visible image content and avoid unsupported objects,
actions, or attributes.

The project also evaluates model behavior under different image
brightness conditions and compares inference latency between the
baseline and fine-tuned models.

## 2. Model and Environment

- Base model: Qwen2.5-VL-3B-Instruct
- Fine-tuning method: DPO + LoRA
- Training epochs: 1
- Learning rate: 5e-6
- DPO beta: 0.1
- Random seed: 20261024
- Training preference examples: 115
- Training loss: 0.592753
- GPU: NVIDIA RTX 5090

The training loss is reported as an optimization statistic and should
not be interpreted as direct evidence of improved caption quality.

## 3. Optimization Objective and Preference Data

The preference data is stored in:

- `data/vlm_preferences_train.jsonl`

The dataset contains 115 preference examples for DPO fine-tuning.

The intended preference is to favor descriptions grounded in image
content over descriptions containing unsupported details.

The fine-tuned LoRA adapter is saved in:

- `checkpoints/dpo_lora_v1/final_adapter/`

The base model and the LoRA adapter are used together for DPO inference.

images. The evaluation used seed 20261023, and the selected evaluation
image IDs did not overlap with the 115 training image IDs.

## 5. Manual Caption Review

A manual review was conducted on a 20-image sample, consisting of
10 high-priority examples selected using an automated heuristic and
10 randomly sampled examples.

Files:

- `results/auto_screen_v1/automatic_screening.csv`
- `results/auto_screen_v1/screening_summary.json`
- `results/auto_screen_v1/manual_review_sample_20.csv`

- `results/eval_dpo_lora_v1/paired_manual_audit.csv`

### Manual review results

| Metric | Baseline | DPO + LoRA |
|---|---:|---:|
| Grounded descriptions rated good | 20/20 | 19/20 |
| Unsupported objects detected | 0/20 | 0/19 rated |
| Unsupported actions or attributes | 0/20 | 1/20 |
| Important objects omitted | 0/20 | 0/20 |

In the pairwise preference review:

- Baseline preferred: 7 images
- Tie: 13 images
- DPO preferred: 0 images

One DPO hallucination rating was missing in the recorded review.
Therefore, the object-hallucination counts should be interpreted
using their actual rated denominators.

These results do not provide evidence that DPO improved visual
grounding in the reviewed sample. The sample is small, and the
high-priority subset was selected heuristically rather than randomly.
The manual assessment also used a single reviewer.

## 6. Brightness Robustness Experiment

The brightness experiment compares the baseline and DPO models
under three image conditions:

| Condition | Brightness factor |
|---|---:|
| Original | 1.0 |
| Darkened | 0.5 |
| Brightened | 1.5 |

The experiment uses 20 images, 3 conditions, and 2 models, resulting
in 120 total generations.

The models use the same prompt and deterministic generation setting
(`do_sample=False`).

Prompt:

> Describe this image in one concise sentence. Mention only objects and actions supported by the image. Do not guess details that cannot be determined from the image.

### Brightness experiment outputs

- Predictions:
  `results/brightness_v1/brightness_predictions.jsonl`
- Comparison:
  `results/brightness_v1/brightness_comparison.csv`
- Summary:
  `results/brightness_v1/brightness_summary.json`

### Mean inference latency

| Model | Original | Darkened | Brightened |
|---|---:|---:|---:|
| Baseline | 0.3083 s | 0.2867 s | 0.2638 s |
| DPO + LoRA | 0.5105 s | 0.4956 s | 0.5191 s |

For original images, DPO inference latency was approximately 65.6%
higher than baseline latency.

### Exact caption stability

The following values count whether the generated caption is exactly
the same text as the caption generated for the original image.

| Model | Original vs. darkened: changed | Original vs. brightened: changed |
|---|---:|---:|
| Baseline | 19/20 | 19/20 |
| DPO + LoRA | 18/20 | 17/20 |

### Exact caption agreement between models

| Condition | Identical captions |
|---|---:|
| Original | 5/20 |
| Darkened | 3/20 |
| Brightened | 6/20 |

DPO had a slightly higher exact-text stability rate in this small
sample. However, exact text matching is not a direct measure of
caption correctness. A caption can change while remaining correct,
and a caption can remain unchanged while being incorrect.

The brightness experiment does not establish that DPO improved
visual recognition accuracy or robustness.

## 7. Main Findings

1. The DPO + LoRA fine-tuning process was completed using 115
   preference examples.
2. Baseline and DPO VLM outputs were evaluated on 100 COCO validation
   images.
3. A 20-image manual review did not show an improvement in grounded
   caption quality for DPO.
4. The brightness experiment completed 120 generations across two
   models and three image conditions.
5. DPO showed slightly higher exact-text stability under brightness
   changes in this sample, but this is not equivalent to improved
   visual understanding.
6. DPO inference was slower than baseline inference in the measured
   experiments.

Overall, the experiments demonstrate a complete fine-tuning and
evaluation workflow, but the current evidence does not establish
that DPO improved the visual grounding of generated descriptions.

## 8. Limitations and Future Work

- Increase the number and diversity of manually reviewed images.
- Use a consistent annotation rubric and, if possible, multiple reviewers.
- Evaluate object hallucination, unsupported actions, omissions, and
  image-caption alignment separately.
- Add image-quality perturbations such as blur or reduced resolution
  if broader robustness testing is required.
- Repeat latency measurements under controlled conditions and report
  the hardware and generation settings.
- Avoid using exact caption similarity alone as a measure of
  visual understanding.

## 9. Reproducibility

Before submitting, verify that all referenced files exist and that
